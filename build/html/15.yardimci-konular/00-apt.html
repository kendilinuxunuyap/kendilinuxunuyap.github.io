apt Paket Sistemi¶

apt paket sistemi debian tabanlı sistemlerde paket yönetimi için kullanılan bir uygulamadır. Temel işlemler şunlardır.

Yerel Paket İndexini Güncelleme¶

sudo apt  update

Paket Yükleme¶

sudo apt install paket_adi

Paket Silme¶

sudo apt remove paket_adi
